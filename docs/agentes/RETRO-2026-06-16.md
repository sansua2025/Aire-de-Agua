## Resumen de aprendizajes

1. **`gh` CLI ausente en entorno remoto.** `merge-gate.sh` no puede correr desde subagentes ni retro.
   Las operaciones GitHub van por `mcp__github__*` desde el orquestador. Follow-up: portar el gate
   a GitHub MCP.

2. **n8n JSON dual-grafo (bug AIR-79).** Los workflows publicados tienen `nodes` (draft) y
   `activeVersion.nodes` (ejecutado). Editar solo `nodes` deja la defensa anti-injection (AIR-119)
   activa en draft pero perdida en producción. Regla: actualizar AMBAS copias y verificar
   `jsCode` byte-idéntico. Candidato a check en CI.

3. **`buscar_brand_knowledge` recibe VECTOR, no texto.** Parámetro es `query_embedding vector(1536)`.
   Generar embedding con `text-embedding-3-small` antes de llamar la RPC.

4. **No insertar learnings de proceso en la tabla `insights`.** `get_memoria_activa(null,...)`
   devuelve los top-10 vigentes de todos los dominios al prompt E5 — contaminaría el contexto.
   Memoria de proceso = MEMORY.md del repo, no Supabase.
